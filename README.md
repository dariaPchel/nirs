# FRAUDI — помощник по выявлению признаков онлайн-мошенничества

## О проекте
FRAUDI — прототип интеллектуального помощника, который помогает пользователю разобраться в подозрительной ситуации: звонке, сообщении, ссылке или просьбе перевести деньги либо сообщить код подтверждения. Пользователь описывает произошедшее своими словами; помощник при необходимости задаёт уточняющие вопросы, ищет релевантные сведения в базе документов и формирует объяснимую оценку риска.

Проект разрабатывается в рамках НИРС «Разработка RAG-приложения с помощью LLM» в МГТУ им. Н. Э. Баумана.

## Запуск

Прототип интерфейса — статичные HTML-страницы, сервер не нужен.

1. Склонировать репозиторий: `git clone https://github.com/dariaPchel/nirs.git`
2. Открыть в браузере `landing.html` с помощью расширения Live Server.

## Основной сценарий
1. Пользователь описывает подозрительную ситуацию.
2. Помощник задаёт уточняющие вопросы, если важных сведений не хватает.
3. По описанию и ответам пользователя выполняется поиск по корпусу документов с помощью BM25.
4. LLM формирует ответ на основе контекста найденных документов и сведений пользователя.
5. Пользователь получает оценку риска, объяснение признаков и рекомендуемые действия.

Пример: пользователь сообщает, что ему позвонили от имени службы безопасности банка и попросили продиктовать код из СМС для отмены кредита. Помощник объясняет, почему это тревожный признак, и рекомендует прекратить разговор и связаться с банком через официальный канал.

## Границы первой версии
- Приложение не устанавливает личность звонившего и не доказывает факт преступления.
- Приложение не обращается к банковским счетам и не выполняет финансовые операции.
- Справочник подозрительных номеров — возможное расширение, а не обязательная функция первой версии.
- Ответ является информационной поддержкой и не заменяет обращение в банк или компетентные органы.
- Авторизация в прототипе не предусмотрена: приложение рассматривается как встроенный компонент банковского сервиса.
