# Правила работы с репозиторием

## Перед началом работы
1. Прочитай `README.md`.
2. Прочитай относящиеся к задаче документы из `spec/product/` и `spec/tech/`.
3. Проверь структуру проекта и последние изменения в `CHANGE_HISTORY.md`.
4. Если требования противоречат друг другу или не определяют ожидаемое поведение, задай вопрос команде либо зафиксируй допущение до реализации.

## Ограничения
1. Делаем только то, что описано в spec/. Новую функциональность сначала добавляем в спецификацию и обсуждаем с командой.
2. Ключи API и пароли не попадают в репозиторий. Они передаются только через переменные окружения (см. spec/tech/architecture.md).
3. Документация пишется на русском языке.
